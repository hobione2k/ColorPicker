# 仕様

## 動作環境

ブラウザ上でローカル動作

## 機能

### 相互に変換取得可能な色形式

* RGBA
* カラーコード
* HSV

### Undo / Redo 機能

* 選択中の色の変更を元に戻す（Undo）・やり直す（Redo）ことができる
* カラーピッカーサークル下部の両端（左: Undo、右: Redo）のボタン、または Ctrl(⌘)+Z / Ctrl(⌘)+Shift+Z・Ctrl(⌘)+Y で操作する
* ドラッグや矢印キーの連続操作は 1 件の履歴としてまとめる
* 履歴は最大 100 件まで保持する（ページを再読み込みすると消える）

### 透明色の背景の切り替え

* プレビュー・透明度スライダー・マイカラーの背景を、市松模様 / 白 / 黒から選べる（初期値は市松模様）
* 画面上部のボタンで切り替え、選んだ背景はブラウザに保存して次回も引き継ぐ
* 背景の色はライト / ダークテーマに関係なく同じにする

### ショートカットキー一覧

* 画面下部に、ショートカットキーの一覧を開閉できるアコーディオンパネルで表示する（初期状態は閉じる）

### マイカラー機能

* 今の色をブラウザローカル上に保存する
* 保存と削除ができる
* 保存した色は画面下部にグリッド上のブロックで表示される
* 保存した色を JSON ファイルにエクスポートできる
* JSON ファイルから色をインポートできる（既存の一覧に追加し、同じ色は追加しない）
