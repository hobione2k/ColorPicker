# ColorPicker

シンプルなカラーピッカー

## 使い方

[ColorPicker](https://hobione2k.github.io/ColorPicker/)または`index.html` をブラウザで直接開くだけで動作します（サーバー不要）。

* 円形ホイールの外周リングで色相、中央の四角で彩度・明度、スライダーで透明度を選択
* カラーコード / RGBA / HSV のどの欄に入力しても、他の形式へ即時に変換
* コピーボタン（書類アイコン）で各形式の文字列をクリップボードへコピー
* 貼り付けボタン（クリップボードアイコン）でクリップボードの色を読み込み（`#4595E6` / `rgba(69, 149, 230, 0.5)` / `hsva(210, 70%, 90%, 1)` / `69,149,230` など）
* 右上のボタンでライト / ダークテーマを切り替え（選択はブラウザに保存）
* 右上の「市松 / 白 / 黒」ボタンで透明色の背景を切り替え（選択はブラウザに保存）

## ディレクトリ構成

```text
index.html            画面
css/style.css         スタイル
js/color-convert.js   色形式の変換処理（RGBA / カラーコード / HSV）
js/app.js             画面の操作・表示処理
js/theme.js           ライト / ダークテーマの切り替え
js/alpha-bg.js        透明色の背景（市松模様 / 白 / 黒）の切り替え
docs/spec.md          仕様
```
